## 1. 프로젝트 전체 구조 이해하기

### 🏗️ 프로젝트는 크게 2부분으로 나뉩니다

```
📦 프로젝트
├── 📂 프론트엔드 (fronteend/fronted)  ← 사용자가 보는 화면
│   ├── src/views/          ← 페이지 파일들 (Vue 컴포넌트)
│   ├── src/api/            ← 백엔드와 통신하는 코드
│   └── src/utils/          ← 재사용 가능한 도구 함수들
│
└── 📂 백엔드 (backend)                 ← 데이터를 처리하는 서버
    └── src/main/java/com/study/domain/
        ├── post/           ← 게시판 관련 코드
        └── guestbook/      ← 방명록 관련 코드
```

### 🔄 프론트엔드 ↔️ 백엔드 통신 흐름

```
👤 사용자
  ↓ (클릭/입력)
📱 프론트엔드 (Vue.js)
  ↓ (HTTP 요청: axios 사용)
🌐 인터넷
  ↓
🖥️ 백엔드 (Spring Boot)
  ↓
💾 데이터베이스 (PostgreSQL)
```

### 🖥️ 백엔드: Post.java (게시글 데이터 형식)

**파일 위치:** `backend/.../post/Post.java`

#### 📝 전체 코드 (64줄)

```java
package com.study.domain.post;
import jakarta.persistence.*;
import java.time.LocalDateTime;

@Entity
@Table(name = "tb_post")
public class Post {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    @Column(nullable = false)
    private String title; // 제목

    @Column(nullable = false, columnDefinition = "TEXT")
    private String content; // 본문의 내용

    @Column(name = "writer_id", nullable = false)
    private Long writerId; // 작성자 ID

    @Column(name = "view_cnt", nullable = false)
    private int viewCnt = 0; // 조회수

    @Column(name = "delete_yn", nullable = false)
    private boolean deleteYn = false; // 삭제 여부

    @Column(name = "created_date", nullable = false, updatable = false)
    private LocalDateTime createdDate = LocalDateTime.now(); // 생성일시

    @Column(name = "modified_date")
    private LocalDateTime modifiedDate; // 수정일시

    public Post() {} // 기본 생성자

    // 게시글 생성용 생성자
    public Post(String title, String content, Long writerId) {
        this.title = title;
        this.content = content;
        this.writerId = writerId;
        this.viewCnt = 0;
        this.deleteYn = false;
        this.createdDate = LocalDateTime.now();
    }

    // Getter와 Setter들
    public Long getId() { return id; }
    public String getTitle() { return title; }
    public void setTitle(String title) { this.title = title; }
    public String getContent() { return content; }
    public void setContent(String content) { this.content = content; }
    public Long getWriterId() { return writerId; }
    public int getViewCnt() { return viewCnt; }
    public void setViewCnt(int viewCnt) { this.viewCnt = viewCnt; }
    public boolean isDeleteYn() { return deleteYn; }
    public void setDeleteYn(boolean deleteYn) { this.deleteYn = deleteYn; }
    public LocalDateTime getCreatedDate() { return createdDate; }
    public LocalDateTime getModifiedDate() { return modifiedDate; }
    public void setModifiedDate(LocalDateTime modifiedDate) {
        this.modifiedDate = modifiedDate;
    }
}
```

package com.study.domain.post;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;
import java.time.LocalDateTime;
import java.util.List;

@Service
public class PostService {
    private final PostRepository postRepository;

    public PostService(PostRepository postRepository) {
        this.postRepository = postRepository;
    }

    // 게시글 저장하기
    @Transactional
    public Long savePost(PostRequest params) {
        Post post = new Post(params.getTitle(), params.getContent(), params.getWriterId());
        return postRepository.save(post).getId();
    }

    // 게시글 조회하기
    public List<Post> findAllPosts() {
        return postRepository.findAllByDeleteYnFalse();
    }

    // 게시글 상세 조회 및 조회수 증가
    @Transactional
    public Post findPostById(Long id) {
        Post post = postRepository.findById(id)
                .orElseThrow(() -> new IllegalArgumentException("게시글을 찾을 수 없다"));
        // 조회수 증가
        post.setViewCnt(post.getViewCnt() + 1);
        return post;
    }

    // 게시글 수정하기
    @Transactional
    public Post updatePost(Long id, PostRequest params) {
        Post post = postRepository.findById(id)
                .orElseThrow(() -> new IllegalArgumentException("게시글을 찾을 수 없습니다."));

        // 제목과 내용 수정
        post.setTitle(params.getTitle());
        post.setContent(params.getContent());
        post.setModifiedDate(LocalDateTime.now());

        return postRepository.save(post);
    }

    // 게시글 삭제하기
    @Transactional
    public void deletePost(Long id) {
        Post post = postRepository.findById(id)
                .orElseThrow(() -> new IllegalArgumentException("게시글을 찾을 수 없다"));
        post.setDeleteYn(true); // DB에서 지우지 않고 상태만 변경

}

    public Guestbook(Long targetId, Long writerId, String content) {
        this.targetId = targetId;
        this.writerId = writerId;
        this.content = content;

### 🖥️ 백엔드: GuestbookService.java

**파일 위치:** `backend/.../guestbook/GuestbookService.java`

#### 📝 전체 코드 (58줄)

```java
package com.study.domain.guestbook;
import jakarta.transaction.Transactional;
import org.springframework.stereotype.Service;
import java.time.LocalDateTime;
import java.util.List;

@Service
public class GuestbookService {
    private final GuestbookRepository guestbookRepository;

    public GuestbookService(GuestbookRepository guestbookRepository) {
        this.guestbookRepository = guestbookRepository;
    }

    /**
     * 방명록 작성
     */
    @Transactional
    public Long saveGuestbook(GuestbookRequest params) {
        Guestbook guestbook = new Guestbook(params.getTargetId(),
                                           params.getWriterId(),
                                           params.getContent());
        return guestbookRepository.save(guestbook).getId();
    }

    /**
     * 특정 사용자의 방명록 조회
     */
    public List<Guestbook> findGuestbooksByTarget(Long targetId) {
        return guestbookRepository.findAllByTargetIdAndDeleteYnFalseOrderByCreatedDateDesc(targetId);
    }

    /**
     * 방명록 수정
     */
    @Transactional
    public void updateGuestbook(Long entryId, String content) {
        Guestbook guestbook = guestbookRepository.findById(entryId)
                .orElseThrow(() -> new IllegalArgumentException("방명록을 찾을 수 없습니다."));

        guestbook.setContent(content);
        guestbook.setModifiedDate(LocalDateTime.now());
        guestbookRepository.save(guestbook);
    }

    /**
     * 방명록 삭제 (논리 삭제)
     */
    @Transactional
    public void deleteGuestbook(Long entryId) {
        Guestbook guestbook = guestbookRepository.findById(entryId)
                .orElseThrow(() -> new IllegalArgumentException("방명록을 찾을 수 없습니다."));

        guestbook.setDeleteYn(true);
        guestbookRepository.save(guestbook);
    }
}
```

#### 📖 한 줄 한 줄 설명

```java

    return guestbookRepository
        .findAllByTargetIdAndDeleteYnFalseOrderByCreatedDateDesc(targetId);
}
```

**의미:** 특정 사용자의 삭제되지 않은 방명록을 최신순으로 조회합니다.

- PostService: 전체 게시글 조회

**의미:** 메서드 이름으로 복잡한 쿼리를 자동 생성합니다.

## 5. 초보자를 위한 용어 사전

### 프론트엔드 용어

**Vue.js**
- JavaScript 프레임워크
- 화면(UI)을 만드는 도구
- 데이터가 바뀌면 화면이 자동으로 업데이트됨

**컴포넌트 (Component)**
- 재사용 가능한 화면 조각
- 예: 버튼, 카드, 페이지 전체 등
- `.vue` 파일로 작성

**ref()**
- 반응형 데이터를 만드는 함수
- 값이 바뀌면 화면이 자동으로 업데이트됨
- `.value`로 값에 접근

**computed()**
- 다른 데이터를 기반으로 계산되는 값
- 의존하는 데이터가 바뀌면 자동으로 재계산됨

**onMounted()**
- 컴포넌트가 화면에 나타날 때 실행되는 함수
- 초기 데이터 로딩에 사용

**v-for**
- Vue의 반복문
- 배열의 각 항목마다 HTML 요소를 생성

**v-model**
- 양방향 데이터 바인딩
- 입력 필드와 데이터를 연결
- 입력하면 데이터가 바뀌고, 데이터가 바뀌면 입력 필드도 바뀜

**axios**
- HTTP 통신 라이브러리
- 백엔드에 데이터를 요청하고 받을 때 사용

**async/await**
- 비동기 작업을 쉽게 처리하는 문법
- 서버 응답을 기다릴 때 사용

### 백엔드 용어

**Spring Boot**
- Java 웹 애플리케이션 프레임워크
- 서버를 쉽게 만들 수 있게 해줌

**@RestController**
- REST API 컨트롤러임을 나타내는 애노테이션
- HTTP 요청을 받아서 처리

**@Service**
- 서비스 계층임을 나타내는 애노테이션
- 비즈니스 로직을 처리

**@Entity**
- 데이터베이스 테이블과 매핑되는 클래스
- JPA가 자동으로 테이블과 연결

**@GetMapping, @PostMapping, @PutMapping, @DeleteMapping**
- HTTP 메서드를 처리하는 애노테이션
- GET: 조회, POST: 생성, PUT: 수정, DELETE: 삭제

**@RequestBody**
- HTTP 요청의 body를 Java 객체로 변환
- JSON → Java 객체 자동 변환

**@PathVariable**
- URL 경로의 일부를 변수로 받음
- 예: `/posts/{id}` → `@PathVariable Long id`

**@Transactional**
- 트랜잭션을 관리하는 애노테이션
- 에러 나면 모든 작업을 취소(롤백)

**JPA (Java Persistence API)**
- Java에서 데이터베이스를 쉽게 다루는 기술
- SQL을 직접 작성하지 않아도 됨

**Repository**
- 데이터베이스에 접근하는 계층
- JpaRepository를 상속하면 기본 CRUD 메서드 자동 생성

**DTO (Data Transfer Object)**
- 데이터를 전송하기 위한 객체
- 예: PostRequest, GuestbookRequest

**Entity**
- 데이터베이스 테이블과 1:1로 매핑되는 클래스
- 예: Post, Guestbook

### 데이터베이스 용어

**테이블 (Table)**
- 데이터가 저장되는 표 형태의 구조
- 행(Row)과 열(Column)로 구성

**컬럼 (Column)**
- 테이블의 열 (세로)
- 데이터의 속성
- 예: id, title, content

**행 (Row)**
- 테이블의 행 (가로)
- 하나의 데이터 레코드
- 예: 게시글 한 개

**기본키 (Primary Key, PK)**
- 각 행을 고유하게 식별하는 값
- 예: id (1, 2, 3, ...)

**외래키 (Foreign Key, FK)**
- 다른 테이블의 기본키를 참조하는 값
- 테이블 간의 관계를 나타냄
- 예: writerId (Member 테이블의 id를 참조)

**CRUD**
- Create: 생성 (INSERT)
- Read: 조회 (SELECT)
- Update: 수정 (UPDATE)
- Delete: 삭제 (DELETE)

**논리적 삭제 (Soft Delete)**
- 데이터를 실제로 지우지 않고 플래그만 변경
- deleteYn = true로 설정
- 복구 가능

**물리적 삭제 (Hard Delete)**
- 데이터를 실제로 삭제
- DELETE 쿼리 실행
- 복구 불가능

### HTTP 용어

**HTTP (HyperText Transfer Protocol)**
- 웹에서 데이터를 주고받는 규약
- 클라이언트-서버 통신의 기본

**HTTP 메서드**
- GET: 데이터 조회 (읽기)
- POST: 데이터 생성 (쓰기)
- PUT: 데이터 수정 (전체)
- PATCH: 데이터 부분 수정
- DELETE: 데이터 삭제

**HTTP 상태 코드**
- 200 OK: 성공
- 201 Created: 생성 성공
- 400 Bad Request: 잘못된 요청
- 401 Unauthorized: 인증 필요
- 404 Not Found: 리소스 없음
- 500 Internal Server Error: 서버 에러

**JSON (JavaScript Object Notation)**
- 데이터를 주고받는 형식
- 사람이 읽기 쉬운 텍스트 형태
- 예: `{"name": "홍길동", "age": 20}`

**API (Application Programming Interface)**
- 프로그램 간의 통신 규약
- 백엔드가 제공하는 기능의 입구
- 예: `/api/posts` (게시글 목록 조회 API)

**REST API**
- REST 원칙을 따르는 API
- 리소스(자원) 중심의 설계
- HTTP 메서드를 의미에 맞게 사용
